# bookmarks

### Introduction

互联网像一条流动的河，总有一些文字、想法与风景，值得停下来。

这个小脚本把收藏变成一次轻轻的点星：从网页到 Issue，再落进这份清单。让偶然的相遇有处可寻，也在 GitHub 上留下一点走过互联网的印记。
